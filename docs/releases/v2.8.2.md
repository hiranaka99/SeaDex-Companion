# SeaDex Companion 2.8.2

The Server log tab is now readable and shareable, so finding what went wrong and reporting it takes a few clicks.

- Errors and warnings stand out. Each entry shows its time, a level label, and the message, with warnings and errors tinted and stack traces dimmed under the entry they belong to. A date heading appears when the day changes.
- Filter by **All**, **Warnings & errors**, or **Errors**, with a count on each.
- **Search log** finds text in any line, including stack traces, and highlights each match.
- **Copy** and **Download** take the entries currently shown, exactly as the server wrote them. Copy also works when you open the app over plain HTTP on your local network.
- **Follow latest** keeps new output in view. Scroll up to read and following pauses, showing how many new entries arrived; select it to jump back to the latest. Output no longer jumps under you while you read.
- Empty results say why, such as "No errors in the latest 500 lines", and offer a way back. If the server cannot be reached, the last lines stay on screen with a note and a retry.
- On phones, each message sits under its time and level so long lines and URLs stay readable.

## Updating

Use `hiranaka/seadex-companion:2.8.2`, `:2.8`, or `:latest` when the Docker images are available for Linux amd64 and arm64.

```bash
docker compose pull
docker compose up -d
```

No configuration changes are required.
