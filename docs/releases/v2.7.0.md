# SeaDex Companion 2.7.0

Usenet downloads. SeaDex Companion can now acquire releases through SABnzbd in addition to qBittorrent, discover what the public Usenet sources carry, and keep both protocols under the same review and control workflow. Torrent downloads continue to work exactly as before.

## Usenet downloads

- Choose **Torrents only**, **Usenet only**, or **Let me choose per release** under **Configuration → Downloads**. Existing installations keep using torrents only until you change it.
- Connect SABnzbd with its server URL and API key, and set the Sonarr and Radarr categories SeaDex Companion should submit to. **Test connection** verifies the setup.
- Usenet sources: AnimeTosho is enabled by default and needs no account. Optionally enable AmeNZB and provide the API key from your amenzb.moe profile. Release details show whether an Usenet source exists for each release, with its size and last check, and let you re-check on demand.
- In **choose** mode, each release offers a Torrent or Usenet method; releases without a public magnet can become Usenet-only, and releases no Usenet source carries stay torrent-only.
- Bulk downloads show the Usenet method only after a provider confirms a usable NZB for every source in the selected release. **All Usenet where available** switches those releases to Usenet and keeps the others on torrents.

## What stays explicit

- Usenet sources cannot be split per episode: the whole upload is downloaded, including files beyond the selected episodes. Bulk and single reviews show exactly which extra files are known and require your acknowledgement before sending.
- Reviews deduplicate shared sources, skip downloads already queued in qBittorrent or SABnzbd, and check free space per client and destination. When a client cannot confirm space, the review says so and asks before continuing.
- If SABnzbd is asked to start a download but the connection drops before confirmation, SeaDex Companion never re-submits it automatically. The download stays listed with **Awaiting confirmation** — check SABnzbd before retrying.
- Progress, pause, resume, and removal are labeled per client. Removing from SABnzbd keeps completed downloads unless you explicitly delete files where the client allows it.
- Changing a client URL keeps the other client's downloads untouched; entries belonging to a different client URL are shown but not controlled until the URL is restored.

## Updating

Use `hiranaka/seadex-companion:2.7.0`, `:2.7`, or `:latest` when the Docker images are available for Linux amd64 and arm64.

```bash
docker compose pull
docker compose up -d
```

Your existing torrents keep their tracking information; no configuration changes are required, and nothing contacts Usenet services until you enable them.
