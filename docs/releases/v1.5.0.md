# SeaDex Companion 1.5

SeaDex Companion 1.5 improves library browsing, release review, configuration, and download monitoring across desktop and mobile. The installed version appears as **v1.5** in the sidebar and mobile header.

## Improvements

- Large libraries render 60 titles per page in both Cards and Table views. Search, filters, status counts, sorting, and bulk review still use the full collection. Opening an entry from scan history takes you to its page.
- Artwork loads lazily and history lookups use indexes, reducing rendering work for large collections.
- Mobile library controls give search and status filtering priority, with secondary options under **View & filters**. Active filters have a visible summary and clear action.
- Navigation, action rows, cards, and dialogs accommodate narrow screens, landscape layouts, enlarged text, and long release names. Mobile content clearance follows the actual header and navigation heights.
- Configuration has clearer field labels and descriptions, more readable controls, and a save footer that leaves the scrolling form usable.
- Release comparisons keep group names, tags, cour explanations, sizes, and download actions readable. Bulk review puts release choices before its compact summary while retaining disk-space warnings and acknowledgement.
- Scan failures offer expandable, scrollable diagnostics without obscuring recovery controls. Error notifications remain available until dismissed.
- The server log uses the available reading space. Following pauses when you scroll back and can be resumed with **Follow live output**.
- Repeated helper boxes, page labels, and excessive emphasis have been reduced. Existing artwork, Signal Blue / Midnight Slate colors, components, and design tokens remain.
- Added product/design documentation and recorded the completed UI audits.

Existing APIs, matching and scheduling behavior, download file scope, credential handling, and file-preservation defaults are preserved. No dependencies were added.

## Validation

- **117 automated tests passed**, including backend build and domain/API regression checks.
- Frontend TypeScript and production build passed.
- Desktop and mobile browser workflows passed, including visible **v1.5** labels, large-library pagination and search, bulk review, configuration, release controls, and recovery.
- Responsive checks cover 320/390/900/1440px widths, landscape, long Latin/Japanese metadata, and enlarged text.
- The final scoped UI audit scored **17/20 (Good)**; the Impeccable detector reported no findings.

Native browser zoom, physical-device safe areas and keyboards, and complete screen-reader workflows remain unverified. See [the implementation and final audit](https://github.com/hiranaka99/SeaDex-Companion/blob/v1.5.0/docs/ui-ux-follow-up-implementation.md) for evidence and validation limits.
