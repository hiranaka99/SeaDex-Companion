# SeaDex Companion 2.6.4

Compact change rows in Scan History, library cards, and Details make it easier to review a scan at a glance.

- See the previous and new release groups inline when SeaDex replaces a recommended torrent.
- Expand **SeaDex note updated** to read the full previous and new notes, including notes for individual cours.
- Newly detected changes retain their before and after values through later scans. Older entries continue to show the details recorded at the time.

## Updating

Use `hiranaka/seadex-companion:2.6.4`, `:2.6`, or `:latest` when the Docker images are available for Linux amd64 and arm64.

```bash
docker compose pull
docker compose up -d
```

The existing scan results provide the baseline for the next scan. No configuration changes are needed.
