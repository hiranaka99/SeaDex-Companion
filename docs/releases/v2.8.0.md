# SeaDex Companion 2.8.0

A clearer library, a scan history you can actually read, and a Configuration page organized around how you set the app up. Your data, settings, and downloads are untouched.

## Library

- A one-line summary now sits above the cards: how many shown titles can be upgraded, the estimated size change if you download all of them, and how many matches need review.
- In the recommended order, titles are grouped under a heading for each status (**Match needs review**, **Upgradable**, **Partially on SeaDex**, **Not on SeaDex**, **Best quality**), each with its title count.
- Cards that need action have an accent border, amber for a match that needs review. Titles already on their best release sit flatter. A short card no longer stretches into an empty panel beside a tall one.
- Season badges now show a symbol as well as a color: an up arrow for upgradable, a check for the best release owned, a minus for not on SeaDex, and a warning for partial coverage. Not-on-SeaDex badges also use a dashed border.
- Selecting a season badge opens **Details** at that season. The **+N** badge opens Details for the remaining seasons.
- Size changes on cards read **+5.6 GB if upgraded**.
- The toolbar is shorter. **Unseen changes** sits with the status filters, **Clear filters** appears next to them when a filter is active, and the filter summary row is gone on desktop. **Coverage status** is now **Any coverage**, so it no longer sounds like the status filters. On phones, Unseen is a compact toggle beside the status menu and the toolbar takes less of the screen.
- Counts show a dash instead of zero while the library is still loading, so a slow load no longer looks like an empty library.

## Scan history

- Scans are grouped under **Today**, **Yesterday**, and earlier dates. Only the latest scan with changes opens by default.
- Each scan shows when it ran, its age, what triggered it, how long it took, and any failed, partial, or cancelled outcome. Actionable changes are summarized first, such as "3 upgradable · 170 removed".
- Long runs of titles that were only added to or removed from your library fold into one expandable group.
- New filters: library app, **Scans with changes** or **Failed or incomplete**, and search by title, release group, or season such as **S02**. **Reset filters** clears them.
- Older scans load ten at a time, and long change lists load forty rows at a time.

## Configuration

- Settings are grouped into **Library**, **Downloads**, **Notifications**, **Automation**, **General**, and **Maintenance** sections. A section opens automatically when a service inside it failed its test, and each collapsed section shows the status of its services.
- **Test connections** moved to the top of the page and tests only the services your download method uses.
- Choosing **Torrents only** hides the SABnzbd and Usenet source cards, and **Usenet only** hides qBittorrent. Missing SABnzbd or Usenet source settings are called out.
- Automatic scans, Discord notifications, AnimeTosho, and AmeNZB use switches with a clickable row. Turning automatic scans off hides the schedule details.
- The Sonarr and Radarr webhook URLs have copy buttons.
- The AnimeTosho feed URL moved under **Advanced: feed URL**.
- SABnzbd, AnimeTosho, and AmeNZB now show their own logos, and the navigation icons for Library, Scan history, Configuration, and Server log were redrawn.

## Updating

Use `hiranaka/seadex-companion:2.8.0`, `:2.8`, or `:latest` when the Docker images are available for Linux amd64 and arm64.

```bash
docker compose pull
docker compose up -d
```

No configuration changes are required.
