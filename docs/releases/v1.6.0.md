# SeaDex Companion 1.6

SeaDex Companion 1.6 removes the standalone **Downloads** tab. The installed version appears as **v1.6** in the sidebar and mobile header.

## Changes

- Removed the **Downloads** page and its sidebar/mobile navigation entry; navigation is now Library, Scan history, Configuration, and Server log.
- Removed the `GET /api/downloads` and `POST /api/downloads/control` endpoints that existed solely to serve that page.
- The per-card active download panel (pause/resume/remove on library cards) and bulk cancellation are unchanged.

The torrent ownership ledger is retained: bulk cancel, log entries, and restart recovery still track app-added torrents. Matching, scheduling, credential handling, and file-preservation defaults are preserved. No dependencies were added.

## Validation

- **116 automated tests passed**, including backend build and domain/API regression checks.
- Frontend TypeScript and production build passed.
- Desktop and mobile browser workflows passed, including visible **v1.6** labels, library browsing, bulk review, configuration, release controls, and recovery.
- Responsive checks cover 320/390/900/1440px widths.
