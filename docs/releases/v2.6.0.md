# SeaDex Companion 2.6.0

See at a glance whether you own the best releases. Details now opens with a clear quality verdict and a compact overview of your seasons, keeping the release groups in your files visible before you expand anything. The installed version appears as **v2.6** in the sidebar and mobile header.

## Changes

- Lead Details with **You have the best releases**, an upgrade count, or a matching-review message, based on the available ownership and coverage evidence.
- Keep **Your release** visible on collapsed season rows. Split seasons show the current release for each cour when episode-level ownership data is available; otherwise, show the season's file groups with an explicit cour-ownership warning.
- Make seasons and cours independently expandable for release sizes, download controls, source links, and recommendation notes.
- Move matching corrections and bulk exclusions into contextual actions. Keep ignored seasons and cours visible in the quality overview.
- Preserve partial SeaDex coverage, unavailable cours, missing-episode counts, and uncertain ownership. A matching group name in incomplete files does not count as a complete best release.
- Open affected details when download activity starts, keeping progress and controls accessible. **Review upgrade** and **Review match** open the relevant season.
- Place **What changed** behind an expandable summary while retaining release-change history and review controls.
- Increase cover artwork to 96 × 144 px on desktop and 64 × 96 px on mobile, with compact artwork on short screens. Shorten the artwork header by removing the extra banner strip below the cover.

## Validation

- All 205 automated tests passed, including per-cour ownership, incomplete files, alternative releases, unavailable cours, uncertain mappings, and missing episodes.
- Server and frontend production builds passed.
- The full browser workflow suite passed, including release overviews, independent keyboard disclosures, download workflows, matching, configuration, and history.
- Release-detail checks covered 320px, 390px, and 1440px widths, enlarged text, long release-group names, and landscape artwork layouts.

Integration and browser checks use isolated local fixtures rather than live Sonarr, AniList, SeaDex, or qBittorrent services.

## Updating

After the release workflow publishes the images, use `hiranaka/seadex-companion:2.6.0`, `:2.6`, or `:latest`. The workflow builds Linux amd64 and arm64 images.

```bash
docker compose pull && docker compose up -d
```

Existing mappings, exclusions, review state, and download safeguards are retained. Run a new library scan if older saved results do not contain episode-level cour ownership information.
