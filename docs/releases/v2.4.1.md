# SeaDex Companion 2.4.1

Fix automatic season alignment, AniList scan failures, and library scrolling. Thanks to [@oakosb](https://github.com/oakosb) for the reports and contributions in [#15](https://github.com/hiranaka99/SeaDex-Companion/pull/15), [#17](https://github.com/hiranaka99/SeaDex-Companion/pull/17), and [#18](https://github.com/hiranaka99/SeaDex-Companion/pull/18). The matching changes were integrated with the 2.4 manual mapping controls in [#19](https://github.com/hiranaka99/SeaDex-Companion/pull/19).

## Changes

- Skip manga and other non-anime sequel relations, and handle missing AniList IDs without aborting the entire scan.
- Align consecutive Sonarr seasons to a continuous AniList entry when their known episode totals match. Combine multiple AniList sequel entries into one Sonarr season when their totals match that season.
- Verify continuous-season releases against the requested season or absolute episode range. Handle independent season uploads and partial batches without substituting different episodes.
- Preserve manual season mappings, including episode offsets when confirming an automatically aligned continuous entry.
- Handle TVDB title years such as `Dororo (2019)` and common long-vowel spelling variants while preferring literal title matches. Refresh older title lookup caches once so previous incorrect matches are reconsidered.
- Share AniList request pacing between searches and scans, respect rate-limit delays, and allow queued scans to cancel promptly.
- Contain hidden accessibility labels within their components and scroll panes, preventing extra document scrollbars and the app shell scrolling into empty space.

## Validation

- All 190 automated tests passed, including a full 17-season Bleach-style scan, four sequel cours, download scope deduplication, manual overrides, ambiguous boundaries, title lookup migration, not-found handling, pacing, and cancellation.
- Server and frontend production builds passed.
- The scrolling fix was reviewed in Edge at 320px, 390px, 900px, and 1440px, with before/after overflow checks, accessibility-tree checks, and the full browser workflow suite.

Integration checks use isolated local fixtures rather than live AniList, Sonarr, SeaDex, or qBittorrent services. Ambiguous episode boundaries remain subject to review; continuous releases without verifiable filenames remain uncovered.

## Updating

After the release workflow finishes publishing, use `hiranaka/seadex-companion:2.4.1`, `:2.4`, or `:latest`. The workflow builds Linux amd64 and arm64 images.

```bash
docker compose pull && docker compose up -d
```

Run a new library scan after updating to apply the matching improvements and refresh older title lookups. Existing manual mappings and exclusions are retained.
