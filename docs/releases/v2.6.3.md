# SeaDex Companion 2.6.3

Fix repeated torrent-change reports and make release changes easier to understand throughout the library and scan history. The installed version appears as **v2.6.3** in the sidebar and mobile header.

## Changes

- Stop reporting unchanged private-tracker torrent placeholders as new torrent changes on every scan. Actual torrent replacements are still detected.
- Show the actual change directly on library cards and in their **What changed** details, including torrent updates and before/after quality values. Keep the affected season, cour, release group, and tracker alongside the change.
- Use the same action-first wording in scan history, with separate lines for separate release updates.
- Replace redundant status transitions such as **Upgradable → Upgradable** with **Still upgradable**. Show status arrows when the status actually changes.
- Improve history descriptions for added and removed titles and resolved upgrades, including older entries without detailed change text.

## Validation

- All 239 automated tests passed, including repeated scans, real torrent replacements, saved baselines, and shared library/history presentation.
- Server and frontend production builds passed.
- Browser workflow checks passed, including library change summaries, release details, history navigation, review controls, and responsive layouts at 320, 390, 900, and 1440 pixels.

Checks use isolated fixtures rather than live Sonarr, AniList, SeaDex, or qBittorrent services.

## Updating

After the release images are published, use `hiranaka/seadex-companion:2.6.3`, `:2.6`, or `:latest`. Images support Linux amd64 and arm64.

```bash
docker compose pull
docker compose up -d
```

Recreate the container to apply the update. No configuration changes are needed. Existing history and unseen changes use the clearer presentation automatically. Previously recorded false change entries remain in history; the fix prevents new false reports on unchanged scans.
