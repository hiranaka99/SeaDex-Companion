# SeaDex Companion 2.9.0

## Hiding titles was removed

The library no longer has a hide button on cards, the **Show hidden titles only** filter, or the **Unhide anime with new best releases** setting.

- Titles you hid before updating appear in the library again. Hiding never stopped their notifications or status tags, so nothing else about them changes.
- To set a season or cour aside, open **Details** and select **Ignore … for bulk** on it. An ignored season or cour gets no bulk download, no Discord notification, and no upgrade tag in Sonarr or Radarr. The library still shows that a better release exists.
- Bulk review now starts with every downloadable row checked. Seasons and cours you ignore are already left out.
- A bookmark that opened the hidden titles now opens the normal library.

## Updating

Use `hiranaka/seadex-companion:2.9.0`, `:2.9`, or `:latest` when the Docker images are available for Linux amd64 and arm64.

```bash
docker compose pull
docker compose up -d
```

No configuration changes are required. Your saved list of hidden titles and the unhide setting are removed from the configuration the next time it is saved.
