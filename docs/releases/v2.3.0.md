# SeaDex Companion 2.3.0

Automatically bring hidden anime back to your library when a scan discovers new best releases on SeaDex.

## Changes

- Add **Unhide anime with new best releases** under **Configuration → Automation & webhooks**. The option is off by default; enable it and save the configuration to use it.
- Restore hidden anime when a best release is added or replaced, including a new torrent from the same release group or a newly covered season/cour.
- Keep anime hidden when only alternative releases, notes, sizes, or selected files change, or when releases are removed.
- Save restored visibility and refresh the open library automatically while preserving unsaved configuration drafts.
- Compare against the previous scan. The first scan after clearing scanned data establishes a new baseline. Hiding an anime again keeps it hidden until another new best release appears.

## Validation

- All 151 automated tests passed, including configuration validation, persisted visibility, scan cancellation and failure handling, and hiding a restored anime again.
- Server and frontend production builds passed.
- Browser workflow checks passed, including keyboard operation and saving of the new setting, desktop/mobile layouts, live library visibility updates, and configuration draft preservation.

Integration and browser checks use local fixtures rather than live Sonarr, Radarr, or qBittorrent services.

## Updating

After image publication completes, use `hiranaka/seadex-companion:2.3.0`, `:2.3`, or `:latest`. The release workflow publishes Linux amd64 and arm64 images.

For Docker Compose deployments using a published image:

```bash
docker compose pull && docker compose up -d
```

Enable **Unhide anime with new best releases** and save the configuration. Manual and scheduled scans then check hidden anime for new best releases.
