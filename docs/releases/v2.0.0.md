# SeaDex Companion 2.0

Sonarr v5 beta is now supported for connection tests and library scans.

## Changes

- Discover Sonarr's advertised API version automatically: API v5 for Sonarr v5 and API v3 for Sonarr v3/v4.
- Use the discovered API for series, episodes, episode files, and connection status.
- Follow Sonarr API redirects, including HTTP 301, within the same origin while preserving API keys and query parameters.
- Block redirects to another origin or URL-supplied credentials; limit redirect chains to five hops.
- Continue accepting service base URLs, reverse-proxy paths, and existing URLs ending in `/api/v3` or `/api/v5`.
- Keep Radarr on API v3.

## Validation

- All 124 automated tests passed on the current main branch with this release's changes.
- Server TypeScript compilation and frontend TypeScript/production build passed.
- A full version 2.0.0 scan over local HTTP fixtures discovered Sonarr API v5, followed HTTP 301 redirects, loaded episode ownership, and persisted the expected upgrade result with one missing episode.
- Compatibility regressions cover Sonarr v4/v5, API discovery redirects, query-preserving redirects, cross-origin credential protection, redirect loops, and unsupported API versions.

Validation used local HTTP fixtures, not a live Sonarr beta container. No SeaDex Companion data migration is required.

## Updating

For a published-image Docker Compose deployment:

```bash
docker compose pull && docker compose up -d
```

For a source-based Docker Compose deployment:

```bash
docker compose up -d --build
```

Keep your existing Sonarr configuration. If a reverse proxy redirects HTTP to HTTPS or changes the host or port, configure the final URL directly; cross-origin redirects remain blocked to protect API keys.
