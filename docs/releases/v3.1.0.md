# SeaDex Companion 3.1.0

This release adds whole-release downloads for split seasons, torrent widening when downloading additional files from an app-managed torrent, and automatic exclusion of releases whose episode numbering does not fit a series' episode order.

## New

- **Whole releases for split seasons.** When AniList treats a long-running series as one continuous entry that Sonarr splits across multiple seasons (such as *Bleach*), each split season's release row now offers **Download whole release** above the season-only download whenever that release covers more than the current season. It sends the entire release as one torrent or one Usenet NZB under the title's download category and tracks the download across every season it covers. The line beneath the button lists the episodes, file count, size, covered seasons, and any seasons that already hold the release; when every covered season already holds it, the button reads **Re-download whole release**.
- **Episode-order mismatch protection.** Season assessment now checks each Sonarr release's regular episode count against your series before narrowing files (reading the episode order such as aired or DVD order from Sonarr v5). Releases whose numbering cannot fit your series—such as segment-split episodes against a combined DVD-order season, or combined episodes against an aired-order season—are marked **Doesn't fit your episode order** with both counts and, on Sonarr v5, the series' episode order. They remain listed with a link to their tracker page, but are never chosen as your target, have no **Download** button, are skipped by bulk download, and trigger no Usenet lookup or sweep. Another fitting release can become your target instead; if only non-fitting better releases exist, the season still shows **Upgrade available** without downloading, notifying, or tagging for them. If your library already holds a non-fitting release, its card notes that your files follow a different episode order than your series.

## Improved

- **Widen app-managed torrents.** When SeaDex Companion previously added a torrent to qBittorrent for a subset of its files, a later download of additional files—or the whole release—from that same torrent now enables those files in the existing torrent instead of skipping it as already queued. Torrents you added yourself are never modified.
- **Safer split-season Usenet handling.** On split seasons whose release covers more than one season, season-only downloads are now torrent-only (both in **Details** and in **Bulk download**, and skipped in **Usenet only** mode) because an NZB cannot be split by season; use **Download whole release** to grab it over Usenet.

## Updating

This release can be installed in-app: open the update notice and select **Install and restart**. You can also pull the new image.

Use `hiranaka/seadex-companion:3.1.0`, `:3.1`, or `:latest` when the Docker images are available for Linux amd64 and arm64.

```bash
docker compose pull
docker compose up -d
```

- **Run a new library scan after updating** so saved results include split-season coverage and episode-order checks. The first scan may record release changes for titles whose target changed because a release does not fit the series' episode order.
- No configuration changes are required.
