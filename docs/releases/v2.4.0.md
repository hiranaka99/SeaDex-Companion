# SeaDex Companion 2.4.0

Match individual Sonarr seasons to separate AniList entries while keeping them together under one anime.

## Changes

- Add **Correct season match** beside each Sonarr season. Select the entry for that season and choose **Save and rescan**, without changing the other seasons or the show's automatic matching anchor.
- Support multiple AniList entries for split cours, in episode order, with controls to reorder or remove entries.
- Give season-specific matches priority over automatic and show-level matches. **Use automatic match** removes only the selected season's override.
- Persist season mappings in `user_rules.json` across rescans, restarts, and clearing scanned data. Existing show-level mappings and exclusions remain supported.
- Refresh AniList season chains and selected entry metadata after 24 hours, on the next scan. A newly observed Sonarr season missing from a recent chain triggers one earlier refresh before requesting review; an unlinked sequel does not force another refresh on every scan.
- Keep confirmed AniList matches without SeaDex coverage distinct from matches needing review, and add season-specific AniList links.
- Preserve selected entries after a failed save and keep matching controls usable on narrow screens.

## Validation

- All 163 automated tests passed, including season override priority, split-cour recommendations and ownership, grouping, persistence, legacy rules, cache refreshes, and HTTP validation.
- Server and frontend production builds passed.
- Browser workflow checks passed, including season-specific selection, cour ordering, save and rescan, failed-save recovery, reset to automatic matching, keyboard handling, and responsive dialogs at 320px and 1440px.

Integration and browser checks use local fixtures rather than live Sonarr, AniList, SeaDex, or qBittorrent services.

## Updating

Rebuild and restart source deployments after updating. Existing user rules remain compatible.

Run a library scan to refresh AniList metadata. If a season still needs review, open the anime's details, select **Correct season match** beside that season, choose its AniList entry, and select **Save and rescan**. For split cours, add entries in episode order.

After image publication completes, Docker deployments can use `hiranaka/seadex-companion:2.4.0`, `:2.4`, or `:latest`. The release workflow publishes Linux amd64 and arm64 images when a GitHub release is published.

```bash
docker compose pull && docker compose up -d
```
