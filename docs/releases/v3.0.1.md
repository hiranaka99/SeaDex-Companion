# SeaDex Companion 3.0.1

This release fixes how SeaDex releases are matched to episodes, which could list a release twice or scope a season's parts to the wrong episodes.

## Fixes

- Re-released episodes named with a version suffix, such as `… - 01v2 [BD 1080p].mkv`, are now recognized. Before, a batch made of such files could be scoped to the wrong cour, so the same release appeared twice in a part (for example the public Nyaa batch beside its AB copy). *Dr. STONE: New World* was affected.
- When your library owns one batch that covers several parts of a season, each part now lists the files from its own episodes. Before, every part showed the first part's files.
- Dot-separated filenames such as `Show.S01E01.1080p.mkv` or `Show.S01E13.100-yen.mkv` are no longer read as fractional episodes (1.1 or 13.1). Half episodes such as `S01E11.5` still are.

## Updating

This release can be installed in-app: open the update notice and select **Install and restart**. You can also pull the new image.

Use `hiranaka/seadex-companion:3.0.1`, `:3.0`, or `:latest` when the Docker images are available for Linux amd64 and arm64.

```bash
docker compose pull
docker compose up -d
```

- **Run a new library scan after updating** so affected titles get corrected release lists. The first scan may record release changes for titles whose selected files changed.
- No configuration changes are required.
