# SeaDex Companion 2.8.1

Fixes a wall of "Not in client" warnings on library cards after upgrading.

- Torrents carried over from older versions that qBittorrent no longer holds no longer appear as "Not in client" with a red "This torrent is no longer in qBittorrent" message. The app now stops tracking them quietly. qBittorrent and your files are never touched.
- A download that the app has seen in qBittorrent and that you later remove there still shows "Not in client", so you can clear it or send it again.
- Nothing is cleaned up while qBittorrent is unreachable.

## Updating

Use `hiranaka/seadex-companion:2.8.1`, `:2.8`, or `:latest` when the Docker images are available for Linux amd64 and arm64.

```bash
docker compose pull
docker compose up -d
```

No configuration changes are required. Leftover warnings clear on their own the next time download progress refreshes.
