# SeaDex Companion 2.5.0

Spot new release recommendations directly in your library, including changes to alternatives, without searching for the anime mentioned in a notification. The installed version appears as **v2.5** in the sidebar and mobile header.

## Changes

- Add **Unseen changes** to the library. Count each anime once across its seasons, apply the current library filters across all pages, and show the latest changes first.
- Label affected seasons on cards with **New best release**, **New alternative**, **Release updated**, or **Release removed**.
- Add **What changed** in Details, with season/cour information, before/after summaries, and detection times.
- Add **Mark reviewed** for one anime and **Mark all reviewed** for all titles matching the current library filters, across every page. Acknowledging existing changes preserves newer changes discovered by another scan.
- Persist review state on the server across scans, restarts, and devices. Opening the app or completing an unchanged scan keeps unseen changes available for review.
- Detect alternative-only additions, removals, replacement torrents, quality and tag changes, recommendation notes, and coverage changes. Record alternative-only updates in Scan history as well.
- Keep ownership changes, local file selection, and reordered release metadata from creating release alerts.
- Keep mobile controls accessible while preserving room for library cards and existing download workflows.

## Updating

After the release workflow publishes the images, use `hiranaka/seadex-companion:2.5.0`, `:2.5`, or `:latest`. The workflow builds Linux amd64 and arm64 images.

```bash
docker compose pull && docker compose up -d
```

Changes appear after completed library scans. Existing saved scan results provide the comparison baseline; a first scan, newly discovered title, or scan after clearing saved data starts without unseen alerts. This release does not retrospectively mark every existing recommendation as new.

Review state is stored in `DATA_DIR/release_changes.json` alongside the existing persistent data. **Mark all reviewed** affects the current library filters across all pages. Hidden titles retain the existing hidden-library behavior.
