# SeaDex Companion 1.8.1

Anime details now keep the title and close control visible while release information scrolls, and distinguish selected download files from the full season or cour release size.

## Changes

- Show the selected-file count and download size, with a disclosure for inspecting filenames before downloading.
- Clearly label current files, season or cour release size, and release size change. Missing file metadata remains explicit.
- Keep the details close control reachable after scrolling, with keyboard focus restored when the dialog closes.
- Put Ignore season directly in the season header, without the Bulk rules dropdown.
- Wrap download errors with recovery guidance and a qBittorrent link. Preserve progress, pause, resume, and removal controls.
- Place library status in a dedicated banner and simplify season pills while retaining accessible cour and ownership information.
- Ignore temporary files, build caches, editor backups, and generated test reports.

## Validation

- All 116 automated tests passed.
- Frontend TypeScript and production build passed.
- Browser workflows cover file scope, missing metadata, downloads, bulk review, cancellation, configuration, focus restoration, and nested dialogs at 320/390/900/1440px widths.

Existing configuration and saved scan data remain compatible. No migration is required.
