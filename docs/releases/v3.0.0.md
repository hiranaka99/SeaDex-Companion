# SeaDex Companion 3.0.0

SeaDex Companion 3.0.0 is a major release adding multi-instance Sonarr and Radarr support, release preferences with exact file-size verification, private-tracker and Usenet search through Prowlarr, import follow-through and status tags, verified in-app updates, and redesigned Library, Details, Scan history, and Configuration views.

## Multi-instance libraries and library scope

- **Additional Sonarr and Radarr instances.** Add multiple Sonarr or Radarr instances (such as a separate 4K library), each with its own URL, API key, download-client category, webhook URL, library scope, matching corrections, and ignored seasons.
- **Library scope.** Limit what each Sonarr or Radarr instance scans by series type (**Only anime series** in Sonarr), included or skipped tags, and root folders, with clickable tag and folder pickers once the instance is connected.

## Exact-release verification and release preferences

- **Exact-release check.** SeaDex Companion now compares your file sizes against the files SeaDex lists for a release, distinguishing multiple releases from the same group and recognizing groupless files. Seasons whose files differ in size from the listed release become **Upgradable**; disable **Check owned releases by file size** under **Configuration → Release preferences** if you remux or modify files after import.
- **Release preferences.** Under **Configuration → Release preferences**, configure how SeaDex Companion picks download targets:
  - **Trackers**: **Include private trackers** (default), **Public trackers only** (keeps owned private releases visible while targeting public releases), or **Include private trackers Prowlarr can reach**.
  - **Download target**: largest (default) or smallest release.
  - **Prefer dual audio**, **Size limit per episode**, **Ignored release groups**, **Ignored trackers**, **Alternatives are good enough**, and **Only my target counts as best**.
- **Release deduplication.** Cross-tracker copies of the same encode, matching video-file subsets, and season releases from full-series batches are deduplicated cleanly while keeping distinct releases from the same group separate.

## Private-tracker releases and Usenet search through Prowlarr

- **Prowlarr integration.** Enable **Find private-tracker releases through Prowlarr** under **Configuration → Downloads → Private-tracker releases** to search Prowlarr indexers for private-tracker torrents and Usenet copies, and for public releases missing from AnimeTosho and AmeNZB.
- **Verified torrent matching.** Private-tracker torrents are sent to qBittorrent only when their files match SeaDex's file list byte for byte.
- **Usenet search, verification, and caching.** Search Prowlarr's Usenet indexers on demand from **Details** or automatically in bulk review, with NZBs checked and labeled (**Files match exactly**, **Names and sizes match (near-exact)**, or manual review for obfuscated/packed/mismatched posts). Search results and checked NZBs persist across restarts in `seadex-data` (`usenet_search.json` and `nzb_store/`).
- **Optional background search and daily limits.** Turn on **Search Usenet indexers in the background** to find candidates after scans without fetching NZBs, with configurable **Daily searches per indexer** (default 100) and **Daily NZB checks per indexer** (default 20).

## Import follow-through, regression alerts, and status tags

- **Import follow-through.** Finished downloads are tracked through Sonarr and Radarr import, triggering a targeted rescan of the title once imported and reporting queue or mismatch problems directly on the download and optionally via Discord (**Import problems**). Importers cleaning up completed downloads no longer trigger missing-download warnings.
- **Regression detection.** Seasons that lose their best release because library files changed are reported as **No longer best** in **Scan history**, **Unseen changes**, and Discord notifications.
- **Expanded webhooks.** Sonarr and Radarr webhooks now support **On File Import**, **On File Upgrade**, and **On Manual Interaction Required** in addition to title additions, with dedicated URLs for additional instances.
- **Status tags in Sonarr and Radarr.** Optionally tag series and movies after each scan with customizable `seadex-best`, `seadex-upgradable`, `seadex-unlisted`, and `seadex-review` tags, plus a one-click action to remove all SeaDex tags.

## Verified in-app updates

- **Update from the app.** Future compatible releases can be installed directly from the version badge in the sidebar (or mobile header) with **Install and restart**. Packages are downloaded from GitHub Releases over HTTPS, verified by SHA-256 checksum, and automatically rolled back if the new version fails to start.
- **Image-required detection.** Releases that change the container runtime, Node.js version, launcher, or server dependencies clearly explain what changed and show the host commands to pull a new image.

## Library, Details, Scan history, and Configuration

- **Configuration tabs.** Settings are now organized into sticky tabs (**Library**, **Downloads**, **Release preferences**, **Notifications**, **Automation**, **General**, and **Maintenance**) with attention indicators, keyboard navigation, the Prowlarr brand icon, and non-wrapping connection badges.
- **Library and downloads.** The library summary now shows estimated download size, net library growth, and reported free disk space. Search, filters, and sort persist in the page URL; **Mark reviewed** and **Mark all reviewed** support **Undo**; desktop operation notices live in the sidebar; multi-torrent downloads collapse under a single summary; and **Cancel downloads** appears only when cancelable downloads exist.
- **Release Details.** Enlarged desktop modal with direct links to tracker pages (such as AnimeBytes and Nyaa), inline low-disk-space confirmation and failure retry for one-click downloads, re-download confirmation, clearer action labels, and preserved keyboard focus.
- **Scan history.** Added a **Since your last visit** digest, grouped change sections, navigable counts linking into filtered library views and server logs, and URL-persisted filters.

## Hiding titles was removed

The library no longer has a hide button on cards, the **Show hidden titles only** filter, or the **Unhide anime with new best releases** setting.

- Titles you hid before updating appear in the library again. Hiding never stopped their notifications or status tags, so nothing else about them changes.
- To set a season or cour aside, open **Details** and select **Ignore … for bulk** on it. An ignored season or cour gets no bulk download, no Discord notification, and no upgrade tag in Sonarr or Radarr. The library still shows that a better release exists.
- Bulk review now starts with every downloadable row checked. Seasons and cours you ignore are already left out.
- A bookmark that opened the hidden titles now opens the normal library.

## Fixes and performance

- Faster scans and page loads: batched AniList metadata refreshes, concurrent Sonarr loads, cached result snapshots, HTTP response compression, static asset caching, lazy-loaded tabs, and filtered qBittorrent progress reads.
- Improved AniList title matching (for example normalizing `×` and trailing `(TV)` so *Kiss x Sis* matches the TV series instead of the OVA).
- Fixed movie releases showing episode labels inferred from audio channel layouts.
- Consistent multi-instance download categories and unified upgrade and scan-comparison rules across library summaries, bulk review, history, tags, and notifications.

## Updating

**This release requires pulling a new Docker image.** It upgrades the runtime to Node.js 26 and adds the built-in launcher needed for future in-app updates.

Use `hiranaka/seadex-companion:3.0.0`, `:3.0`, or `:latest` when the Docker images are available for Linux amd64 and arm64.

```bash
docker compose pull
docker compose up -d
```

- **Run a new library scan after updating** so saved results include SeaDex file lists (for exact-release checks and Prowlarr matching) and Sonarr alternate titles. With exact-release checking enabled, seasons whose files differ in size from the listed release may switch from best to upgradable.
- No manual configuration changes are required; the removed `hidden` and `unhide_on_new_best` settings are cleaned up automatically the next time configuration is saved.
- Keep your `seadex-data` volume and its backups private (when Prowlarr Usenet search is used, it also stores `usenet_search.json` and `nzb_store/`).
