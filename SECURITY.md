# Security policy

## Supported versions

Security fixes are provided for the latest published container version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository:

https://github.com/hiranaka99/SeaDex-Companion/security/advisories/new

Include the affected version, deployment model, reproduction steps, and impact. Expect acknowledgement within seven days. A fix and disclosure timeline will be coordinated after validation.

## Deployment boundary

SeaDex Companion is designed for a trusted home network. Direct internet exposure is not recommended. If remote access is required, place it behind an HTTPS reverse proxy or private VPN and keep the administrator password unique.
