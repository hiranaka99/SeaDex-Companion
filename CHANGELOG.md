# Changelog

All notable changes are documented here. Releases follow semantic versioning.

## 1.0.0 - 2026-09-08

- Initial public release.
- Sonarr and Radarr library comparison against SeaDex.
- qBittorrent downloads and bulk controls.
- AniList matching, scan history, Discord notifications, and scheduled scans.
- Password-protected WebUI with encrypted integration credentials.
- Hardened container runtime, health checks, security headers, and automated release gates.
- Default Docker Compose port publishing is restricted to the loopback interface.
